# Collab Security Policy

**Effective Date:** April 1, 2026

Collab takes security seriously and applies safeguards to protect your data.

## 1. Data Protection
- Encrypted collaborators (HTTPS)
- Role-based access control
- Restricted access to sensitive data

## 2. Account Security
- Passwords are stored securely (hashed)
- Users are encouraged to use strong passwords

## 3. Access Controls
- Contact details are hidden by default
- Team data is only shared with authorized contributors
- Admin access is limited and logged

## 4. Reporting Security Issues
If you discover a vulnerability, report it to **helpdesk@joincollab.org**. We will respond promptly.

## 5. Availability
We monitor uptime and maintain backups. Free-tier hosting may cause cold starts, but core data is preserved.
